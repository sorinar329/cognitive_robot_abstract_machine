# IEA-3.4-130-RWT reference data

`IEA-3.4-130-RWT.yaml` is the windIO description of the IEA Wind Task 37 land-based
3.4 MW reference turbine, copied from
https://github.com/IEAWindSystems/IEA-3.4-130-RWT (Apache-2.0, see `LICENSE`).
Report: Bortolotti et al., *IEA Wind TCP Task 37: Systems Engineering in Wind Energy -
WP2.1 Reference Wind Turbines*, NREL/TP-5000-73492, 2019.

`geometry.json` is the subset we model (blade planform and airfoils, tower, hub,
drivetrain outer shape), written by `scripts/import_iea_reference.py`.
